# Code of conduct

DupeSweep is a small project, and everyone who takes part should be able to do so without harassment.

**Expected:** be respectful and patient, keep discussion about the work, give and accept constructive feedback, and
assume good intent.

**Not acceptable:** harassment, insults or personal attacks; discriminatory language; publishing someone's private
information; sustained disruption of discussions; and any other conduct that would be inappropriate in a professional
setting.

**Enforcement:** the maintainer (@devid9602) may edit or remove comments, close issues or pull requests, and block
people who don't follow this code. To report a problem privately, use the contact details on the maintainer's
GitHub profile.

This code applies in the issues, pull requests and discussions of this repository, and wherever someone represents
the project.
